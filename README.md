# BlueTone Studio 公開文書

価格マップ（旧称 DiscoveryMap）のプライバシーポリシーと利用規約は、2026-11 に https://kakakumap.com/legal/ （リポジトリ [BlueToneStudio/discoverymap-lp](https://github.com/BlueToneStudio/discoverymap-lp) の `legal/`）へ移した。文書の改定はそちらで行う。

このリポジトリの各ページは、旧 URL を開いたときに新 URL へ転送するだけのページ。配信中のアプリのログイン画面が旧 URL を開くため、ページは残す。

| 旧 URL | 転送先 |
|---|---|
| https://bluetonestudio.github.io/legal/privacy-policy.html | https://kakakumap.com/legal/privacy-policy |
| https://bluetonestudio.github.io/legal/terms.html | https://kakakumap.com/legal/terms |
| https://bluetonestudio.github.io/legal/account-deletion.html | https://kakakumap.com/legal/privacy-policy#deletion |
| https://bluetonestudio.github.io/legal/ | https://kakakumap.com/legal/ |

master に push すると GitHub Pages で自動で公開される。
