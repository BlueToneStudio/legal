価格マップ プライバシーポリシー

BlueTone Studio（以下「当方」といいます）は、スマートフォンアプリ「価格マップ」（Android 版・iOS 版。旧称「DiscoveryMap」。以下「本アプリ」といいます）と、本アプリの紹介サイト kakakumap.com（以下「本サイト」といいます）で取り扱う利用者の情報について、次のとおり定めます。

1. 取得する情報と利用目的

情報取得するとき利用目的
ユーザー ID（Firebase Authentication が発行する識別子）本アプリを初めて起動したとき。ゲストとして自動的に発行しますログイン状態の維持、登録した情報との紐付け
氏名、メールアドレス、プロフィール画像の URLGoogle アカウントでログインしたとき。Apple でサインインしたとき（iOS 版）は氏名とメールアドレスのみで、「メールを非公開」を選ぶと Apple が発行する中継用のメールアドレスになりますアカウントの識別・管理、アプリ内でのプロフィール表示
登録した情報（商品名、バーコードの値、価格、メモ、店舗、登録日時）価格や商品を登録したとき価格の記録と地図上での共有、商品の特定
棚札写真と読み取り結果「棚の写真から一括登録」で写真を送信したとき棚札の商品名・価格の読み取り、読み取り結果の確認画面での表示、読み取り精度の検証と改善

利用状況（表示した画面、操作、端末と OS の情報、アプリのインスタンス ID、広告 ID〔Android 版〕、IP アドレスから推定されるおおよその地域）ストアから配布する本アプリを使ったとき。Google アナリティクス for Firebase が取得します利用状況の把握と本アプリの改善。当方はこれらの記録を氏名・メールアドレスと結び付けません
広告 ID〔Android 版〕、IP アドレス、端末の情報本アプリを起動したとき。組み込んでいる Google AdMob の SDK が取得することがあります。現在、本アプリは広告を表示していませんGoogle による広告の配信、効果測定、不正の防止
メールアドレス、お問い合わせの内容、アプリのバージョン、端末の機種名と OS のバージョン設定画面の「お問合せ・報告」（Google フォーム）から送信したとき、またはメールでお問い合わせいただいたときお問い合わせへの対応、ご本人の確認、不具合の調査、重複した報告や不正な報告への対策
IP アドレス、端末とアプリの情報、Firebase のインストール ID本アプリがサーバーと通信するときサービスの提供、障害の調査

位置情報、カメラ、写真ライブラリの利用は、端末の設定からいつでも停止できます。停止しても、地図は既定の位置（東京）を中心に表示でき、商品名と価格の手入力で本アプリを利用できます。Android 版では、端末の設定から広告 ID をリセット・削除できます。

登録した価格の情報は公開されます。商品名、価格、店舗、登録日時、メモは本アプリの他の利用者の地図や一覧に表示されます。保存されている価格の情報には登録した利用者のユーザー ID も含まれ、本アプリの外からも取得できる状態で公開されます。メモに氏名や連絡先など個人を特定できる内容は書かないでください。商品名とバーコードの値は、本アプリにログインしている利用者全員が見られます。棚札写真と読み取り結果は他の利用者には公開しません。当方と委託先は、上記の目的の範囲で取り扱います。

3. 第三者への提供

当方は、法令に基づく場合を除き、本人の同意なく個人情報を第三者に提供しません。保存や解析など、本アプリの提供に必要な処理の一部を外部の事業者に委託します。登録した価格の情報は、第 1 条のとおり公開されます。価格・商品・店舗に関する情報を個人を識別できない形に加工した統計データは、第三者に提供することがあります。

4. 保持期間とアカウントの削除

  • アカウント情報（氏名、メールアドレス、プロフィール画像の URL、ログインの情報）は、アカウントが削除されるまで保持します。
  • お問い合わせの内容は、対応に必要な期間保持します。
  • 当方のサーバー（Cloud Functions）の実行の記録は、30 日間保持します。

アカウントの削除は、本アプリにログインした状態で設定画面を開き、「アカウントを削除」を選んで確認画面で「削除」を押すと行えます。ログインに使った Google アカウントまたは Apple ID での確認を求められた場合は、画面の案内に従ってください。

削除すると、アカウント情報（氏名、メールアドレス、プロフィール画像の URL、ログインの情報）を削除し、ログインに使った Google アカウントまたは Apple ID との連携の解除処理を行います。削除したアカウントは元に戻せません。ゲストのアカウントは本アプリから削除できません。

本アプリは、地図の店舗情報のキャッシュと商品検索の履歴を端末内に保存します。

5. 安全管理措置

本アプリとサーバーとの通信は TLS で暗号化しています。データは Google の Firebase と Google Cloud 上に保管し、棚札写真と読み取り結果には、他の利用者がアクセスできないようアクセス制御を設定しています。登録した情報、棚札写真、読み取り結果は日本（東京リージョン）に保存します。Firebase Authentication、Google アナリティクス、Google AdMob、Gemini API、ML Kit（Google LLC）と Sign in with Apple（Apple Inc.）では、米国など日本以外の国で情報が処理されることがあります。Google LLC と Apple Inc. の各サービスは、各社のプライバシーポリシーと利用規約に基づき、本ポリシーと同等の水準で情報を保護します。各社の取り扱いは第 2 条の関連文書をご覧ください。
