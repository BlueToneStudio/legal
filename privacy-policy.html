価格マップ プライバシーポリシー

BlueTone Studio（以下「当方」といいます）は、スマートフォンアプリ「価格マップ」（Android 版・iOS 版。旧称「DiscoveryMap」。以下「本アプリ」といいます）および本アプリの紹介 Web サイト（以下「本サイト」といいます）における利用者の情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

本アプリの機能は、アプリのバージョン・端末・OS によって一部提供されないことがあります。本ポリシーは、利用者が使った機能について適用されます。

1. 取得する情報と利用目的

1-1. アカウント情報

情報取得するとき利用目的
ユーザー ID（Firebase Authentication が発行する識別子）本アプリを初めて起動したとき（ゲストとして自動的に発行します）ログイン状態の維持、登録した情報との紐付け
氏名（表示名）・メールアドレス・プロフィール画像の URLGoogle アカウントでログインしたときアプリ内でのプロフィール表示、アカウントの識別・管理
メールアドレス・氏名Apple でサインインしたとき（iOS 版のみ）。Apple の「メールを非公開」を選んだ場合は、Apple が発行する中継用のメールアドレスになりますアカウントの識別・管理

本アプリは、初回の起動時にゲストとして利用を始めます。ゲストの間は氏名・メールアドレスを取得しませんが、価格情報の登録や棚札写真の送信など、以下に記載する情報は取得します。ゲストから Google アカウントまたは Apple でログインした場合、ゲストの間に登録した価格情報と商品の表示名をログイン後のアカウントに引き継ぎます。棚札写真とその読み取り結果は引き継がず、ゲストのユーザー ID のまま残ります。すでに使っていた Google アカウントや Apple ID に切り替えた場合などは、価格情報と表示名も引き継げないことがあります（利用規約 第 4 条）。引き継ぎのため、ゲストのユーザー ID とログイン後のユーザー ID の対応を一時的に保存します。

Google アカウントのプロフィール画像は、設定画面で表示する際に画像の配信元（Google など）から直接読み込みます。

1-2. 利用者が登録する情報と公開範囲

情報内容公開範囲
価格情報商品、価格、メモ（任意）、店舗の識別子（OpenStreetMap の ID）、登録・更新日時、登録した利用者のユーザー ID公開（下記のとおり）
商品情報商品名、バーコードの値（読み取った場合）、商品を最初に登録した利用者のユーザー ID、作成日時本アプリの利用者に公開
商品の表示名（任意）自分の画面だけに表示する商品名本人のみ

利用目的は、価格情報の記録・表示、地図上での価格情報の共有、商品の特定という本アプリの機能の提供です。

商品を名前で検索するとき、入力した文字は商品を探すために Cloud Firestore に送信します。検索した文字そのものを当方のサーバーに保存することはありません。

価格情報は公開されます。価格情報は本アプリの他の利用者の地図や一覧に表示され、本アプリの利用者以外も技術的に取得できる状態で保存されます。公開されるデータには、商品・価格・店舗・登録日時のほか、登録した利用者のユーザー ID（氏名やメールアドレスではない識別子）とメモが含まれます。メモは本アプリの画面では登録した本人にしか表示しませんが、公開されるデータに含まれるため、氏名や連絡先など個人を特定できる内容は書かないでください。

1-3. 棚札写真

「棚の写真から一括登録」の機能で送信した写真（以下「棚札写真」といいます）は、次のとおり取り扱います。

  • 棚札写真は、縮小や加工をせず、撮影されたデータのまま Cloud Storage for Firebase に保存します。写真に撮影日時・撮影場所（GPS 座標）・端末の機種名などの付随情報（EXIF）が含まれている場合は、それらも併せて保存されます。
  • 写真を送信すると、店舗の識別子・店舗名・送信日時・処理の状態などを Cloud Firestore に保存します。当方のサーバー（Cloud Functions）は、写真から撮影日時・撮影場所・端末の機種名と画像の大きさを取り出して、あわせて保存します。
  • 当方のサーバーは、棚札に書かれた商品名・価格を読み取るため、写真を Google の Gemini API に送信します。送信する写真には、付随情報（EXIF）が含まれることがあります。読み取り結果は Cloud Firestore に保存します。
  • 利用目的は、棚札の商品名・価格の読み取り、読み取り結果の確認画面での表示、読み取り精度の検証・改善と再解析、および撮影日時・撮影場所による登録内容の確認です（利用規約 第 9 条）。
  • 棚札写真と読み取り結果は、本アプリでは送信した本人だけが閲覧できます。当方は上記の目的のために参照することがあります。
  • 他の来店者や従業員などが写り込まないようにしてください（利用規約 第 9 条）。

1-4. 位置情報

本アプリは、地図の中心の決定、現在地の表示、店舗までの距離の表示のために端末の位置情報を利用します。端末の位置情報（GPS 座標）そのものを当方のサーバーに送信・保存することはありません。

  • 地図と店舗の情報を取得するため、表示中の地図の範囲（表示範囲より少し広い緯度経度の範囲）や店舗の識別子を、第 2 条の地図関連サービスに送信します。本アプリは起動時に現在地を中心に地図を表示するため、送信する範囲から利用者のおおよその位置が分かることがあります。
  • 棚札写真に撮影場所（GPS 座標）が含まれている場合は、1-3 のとおり保存します。
  • 位置情報の利用は端末の設定からいつでも拒否できます。拒否した場合も、既定の位置（東京）を中心に本アプリを利用できます。

1-5. カメラと写真

  • 本アプリは、商品バーコードの読み取りと、棚札の文字・バーコードの読み取り（棚札ライブ）にカメラを利用します。これらのカメラの映像は端末内で処理し、映像を保存したり当方のサーバーへ送信したりすることはありません。送信するのは、読み取ったバーコードの値と、利用者が確認して登録した価格情報です。
  • 棚札写真の撮影と、端末内の写真の選択にカメラと写真ライブラリを利用します。選んだ写真は 1-3 のとおり送信・保存します。
  • 設定画面の評価用の機能（バーコード読み取りの比較）で選んだ写真は、端末内で処理し、送信しません。処理のための一時ファイルは処理の後に削除します。
  • Android 版の端末内での読み取りには Google の ML Kit を使います。ML Kit は、端末とアプリの情報や利用状況の統計を Google に送信することがあります。
  • カメラと写真ライブラリの利用は端末の設定からいつでも拒否できます。拒否した場合も、商品名と価格の手入力で本アプリを利用できます。

1-6. バーコードによる商品名の検索

読み取ったバーコードの値が商品情報に無い場合、当方のサーバーがその値を Google の Gemini API（Google 検索による確認を含みます）に送信し、商品名を調べます。送信するのはバーコードの値だけで、ユーザー ID や位置情報は送信しません。調べた結果を採用しなかった場合やエラーの場合は、障害の調査のため、バーコードの値と商品名の候補を当方のサーバーの記録に残すことがあります（1-12 の記録と同じく 30 日間保存します）。

1-7. 利用状況の分析（Google アナリティクス for Firebase）

ストア（テスト配信を含みます）から配布する本アプリでは、Google が提供する Google アナリティクス for Firebase を使い、表示した画面と操作（ボタンを押したことなど）の記録を送信します。当方は、これらの記録をユーザー ID・氏名・メールアドレスと結びつけません。あわせて、Google アナリティクス for Firebase は、アプリのインスタンス ID、広告 ID（Android 版）、IP アドレスから推定されるおおよその地域、端末・OS の情報、初回起動やセッションなどの情報を自動的に取得することがあります（Google の開示によります）。

利用目的は、利用状況の把握と本アプリの改善です。

1-8. 広告（Google AdMob）

  • 本アプリは Google が提供する Google AdMob を組み込んでいます。現在は広告の表示を停止していますが、今後、本アプリ内に広告を表示することがあります（利用規約 第 13 条）。
  • Google AdMob の SDK は、広告を表示していない間も本アプリの起動時に初期化されます。SDK は、広告 ID（Android 版）・IP アドレス・端末の情報などを取得し、広告の配信・効果測定・不正の防止や、利用者の興味に応じた広告の表示に使うことがあります（Google の開示によります）。
  • Android 版では、端末の設定から広告 ID を削除・リセットできます。iOS 版はトラッキングの許可を求めないため、広告用の識別子（IDFA）は使用しません。
  • 当方が、利用者の登録した情報（価格情報・棚札写真など）を広告主に提供することはありません。

1-9. お問い合わせ・報告

設定画面の「お問合せ・報告」から開く Google フォームで、お問い合わせと報告を受け付けます。このフォームでは、メールアドレス（必須）、お問い合わせの種別と内容、対象の店舗名・商品名（任意）のほか、本アプリが自動で入力するアプリのバージョン、端末の機種名と OS のバージョンを取得します。メールでお問い合わせいただいた場合は、メールアドレスとお問い合わせの内容を取得します。

利用目的は、お問い合わせへの回答と確認のためのご連絡、ご本人の確認、不具合の調査、重複した報告や不正な報告への対策です。

1-10. 価格の共有

本アプリから価格を共有する場合、商品名・価格・店舗名と、商品と店舗の識別子を含むリンクを、利用者が選んだアプリに渡します。リンクにユーザー ID は含みません。リンクを開いた人が本アプリを入れていない場合は、本サイトが表示されます。

1-11. 端末内に保存する情報

本アプリは、地図の店舗情報と最後に取得した地図の範囲のキャッシュ（最大 7 日間）、商品検索の履歴（最大 10 件）とその履歴を使ったユーザー ID、ログイン状態などを端末内に保存します。これらの保存した内容を当方のサーバーに送信することはありません。本アプリを端末から削除すると、端末内の情報も削除されます。

1-12. 通信に伴って送信される情報

本アプリが Firebase の各サービスや当方のサーバーと通信する際、IP アドレス、端末とアプリの情報、Firebase のインストール ID などが Google に送信されます。当方のサーバー（Cloud Functions）へのアクセスの記録（IP アドレス、通信元のアプリの情報など）は、障害の調査のため 30 日間保存します。

3. 情報の第三者提供

  • 当方は、法令に基づく場合を除き、本人の同意なく利用者の個人情報を第三者に提供しません。第 2 条のサービスへの送信は、本アプリの機能を提供するために行うものです。
  • 1-2 のとおり、価格情報は利用者が登録した時点で公開されます。
  • 当方は、利用規約 第 16 条のとおり、価格・商品名・店舗に関する情報を個人を識別できない形に処理したうえで、統計データの作成などに利用し、その統計データを第三者に提供することがあります。

4. 外国にある第三者による取り扱い

Cloud Firestore・Cloud Storage for Firebase・Cloud Functions のデータは、日本（東京リージョン）に保存します。一方、Firebase Authentication、Google アナリティクス for Firebase、Google AdMob、Gemini API、ML Kit（いずれも米国の Google LLC）、Sign in with Apple（米国の Apple Inc.）、Overpass API と OpenFreeMap（国外の運営者）では、日本以外の国で情報が処理・保存されることがあります。これらの事業者は、それぞれのプライバシーポリシー等に基づいて情報を取り扱っています。外国の個人情報の保護に関する制度は、個人情報保護委員会の公表資料をご覧ください。

5. 保持期間と削除

5-1. 保持期間

  • アカウント情報は、アカウントが削除されるまで保持します。
  • 価格情報・商品情報・商品の表示名は、期間を定めずに保持します。
  • 棚札写真（付随情報を含みます）と読み取り結果は、1-3 の目的のため、期間を定めずに保持します。
  • お問い合わせの内容は、対応に必要な期間保持します。

5-2. アカウントの削除

アカウントは、本アプリの設定画面（ログイン中の場合）から削除できます。アプリから削除できない場合は、アカウント削除のページの手順で削除を申請できます。

区分対象
削除するものアカウント情報（氏名・メールアドレス・プロフィール画像の URL・ログインの情報）。ユーザー ID と氏名・メールアドレスとの対応も削除します。Google アカウントでログインしていた場合は本アプリへの Google アカウントの連携を、Apple でサインインしていた場合は Apple の認可を、それぞれ解除します。連携の解除に失敗した場合も、アカウントの削除は完了します。Google アカウントの設定画面から本アプリの連携を解除できます。
削除後も残るもの登録した価格情報、商品情報、商品の表示名、棚札写真（付随情報を含みます）とその読み取り結果。これらには削除前のユーザー ID が残りますが、ユーザー ID から氏名やメールアドレスをたどることはできなくなります。価格情報は削除後も他の利用者に表示され、削除したアカウントからは編集・削除できなくなります。
  • 削除したデータも、障害に備えたバックアップに最大 7 日間残り、その後消去されます。
  • ゲストのアカウントは、本アプリから削除できません。ゲストの間に登録した情報の削除を希望する場合は、第 11 条のお問い合わせ先にご連絡ください。
  • 端末内の情報（1-11）は、アカウントを削除しても端末に残ります。本アプリを端末から削除すると消去されます。

6. 安全管理措置

本アプリとサーバーとの通信は、すべて TLS で暗号化しています。データは Google Firebase の基盤上に保管し、本人だけが読み書きできる情報には、本人以外がアクセスできないようアクセス制御を設定しています。

7. 開示などの請求

利用者は、当方が保有する自己の個人情報について、利用目的の通知、開示、訂正・追加・削除、利用の停止・消去、第三者への提供の停止を求めることができます。第 11 条のお問い合わせ先までご連絡ください。ご本人であることを確認したうえで、法令に従って対応します。

8. お子様のプライバシー

本アプリは特定の年齢層を対象としたものではありません。未成年の方は、法定代理人の同意を得たうえで本アプリを利用してください（利用規約 第 5 条）。

9. 本サイトのアクセス解析

本サイトでは、利用状況を把握するために Google LLC が提供する Google アナリティクスを使用しています。Google アナリティクスは Cookie を用いて、閲覧したページ・参照元・閲覧に使用したブラウザや端末の種類・おおよその地域などの情報を収集します。これらの情報に氏名やメールアドレスなど個人を特定する情報は含まれません。

収集された情報は Google のプライバシーポリシーに基づいて管理されます。Google がデータを収集・処理する仕組みは「Google のサービスを使用するサイトやアプリから収集した情報の Google による使用」をご覧ください。Google アナリティクスによる情報の収集は、ブラウザの Cookie 設定、または Google アナリティクス オプトアウト アドオンで無効にできます。

本サイトにはお問い合わせフォーム等はなく、本サイト自体が氏名・メールアドレスなどの個人情報を収集することはありません。
